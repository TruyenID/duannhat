# TempoFast

Laravel 13 (PHP 8.4) API for shop & inventory management.

## Setup

Có 2 cách chạy local — chọn 1:

1. **[Setup with Docker](docs/guide/setup-docker.md)** — không cần cài PHP/MySQL, một lệnh `docker compose up` là chạy.
2. **[Setup without Docker (Herd)](docs/guide/setup-local.md)** — chạy native qua Laravel Herd, nhanh hơn cho dev hằng ngày, nhưng cần cài PHP 8.4 + MySQL.

## Project structure

```
.
├── app/                    # Laravel application code
├── bootstrap/              # Laravel bootstrap
├── config/                 # Laravel config
├── database/               # Migrations, factories, seeders
│   └── migrations/omnify/  # Auto-generated by omnify (DO NOT EDIT)
├── app/Sso/                # Platform JIT user provisioning
├── public/                 # Web root
├── resources/              # Views (none — API-only)
├── routes/                 # API + console routes
├── schemas/                # Omnify schema YAMLs (single source of truth)
├── storage/                # Logs, app storage
├── tests/                  # Pest tests (Feature, Unit, Browser)
├── docs/                   # Diátaxis docs (guide / explanation / reference / contributing)
├── plans/                  # Plan-driven implementation tracker
├── omnify.yaml             # Omnify codegen config
├── docker-compose.yml      # Docker dev stack
└── composer.json           # Laravel deps
```

> Đây là **API-only** project. Không có Blade views, không có frontend. Frontend sống ở repo riêng `godx-jp/godx-tempo-frontend`.

## MCP servers (Claude Code / Cursor)

Project khai báo các MCP servers ở `.mcp.json` (root):

| Server | Command | Mục đích |
|---|---|---|
| `omnify` | `omnify mcp` | Introspect Omnify schema/types/validation (cần `omnify.yaml` ở root) |
| `playwright` | `npx @playwright/mcp@latest` | Browser automation cho test E2E qua AI |
| `laravel-boost` | `php artisan boost:mcp` | Laravel-specific tools (search docs, DB query, schema, tinker…) |

### Bật MCP trong Claude Code

Project-scoped `.mcp.json` **không tự động được trust** — Claude Code yêu cầu approve thủ công, nếu không sẽ bỏ qua toàn bộ servers (kể cả `claude mcp list` báo `Connected`). Có 2 cách:

**Cách 1 — qua dialog:** Trong Claude Code gõ `/mcp`, chọn approve các server bạn muốn (đừng dismiss dialog).

**Cách 2 — sửa trực tiếp** `.claude/settings.local.json`:

```json
{
  "enabledMcpjsonServers": ["omnify", "playwright", "laravel-boost"]
}
```

Sau khi bật, **đóng hẳn** session và mở lại (không phải reload) — tools `mcp__omnify__*`, `mcp__playwright__*`, `mcp__laravel_boost__*` sẽ available cho AI gọi ngầm.

> **Lưu ý:** Các server này chỉ expose **tools**, không expose **prompts** — vì vậy sẽ **không có** slash command kiểu `/omnify:xxx`. AI sẽ tự chọn tool khi cần, bạn không phải gõ command nào.

### Bật MCP trong Cursor

`.cursor/mcp.json` đã có sẵn cùng nội dung. Cursor tự load không cần approve.

### Verify từ CLI

```sh
claude mcp list
```

Kết quả mong đợi: `omnify ✓ Connected`, `playwright ✓ Connected`, `laravel-boost ✓ Connected`.
