# PLAN-043 — Tax types (軽減税率 / インボイス)

## P43-1 — Tax types CRUD (curl HQ API + UI)
```
GET /api/v1/hq/betoya/tax-types  →  HTTP 200
  EXEMPT   (非課税)    dine_in=0%   takeaway=0%    default=false
  REDUCED  (軽減税率)  dine_in=10%  takeaway=8%    default=false
  STANDARD (標準税率)  dine_in=10%  takeaway=10%   default=true
```
**UI** — `p43-taxtypes-admin.png`: trang HQ 税区分 hiển thị đúng 3 loại (非課税 0/0, 軽減税率 店内10%/持ち帰り8%, 標準税率 10/10 [デフォルト]), cột 商品数 + ステータス Active.
✅ CRUD + seed 3 loại chuẩn Nhật khớp data.

## P43-2 — Rate resolution: dine-in vs takeaway (`TaxResolver` engine)
```
REDUCED food, dine_in     → rate=10%
REDUCED food, takeaway    → rate=8%
```
✅ Rate = giao của item × order type.

## P43-3 — Per-line snapshot bất biến + group-once rounding (order thật)
```
ORDER ORD-2026-0001  dine_in  total=5452  tax=496
per-line snapshot (immutable):
  line qty=1 unit=580  tax_rate=10%  tax_amount=58
  line qty=2 unit=720  tax_rate=10%  tax_amount=144
  line qty=3 unit=620  tax_rate=10%  tax_amount=186
  line qty=2 unit=420  tax_rate=10%  tax_amount=84
per-rate breakdown (group-once — インボイス):
  order_conditions: tax | source=tax_type | rate=10% | amount=496 | label="10%"
```
✅ Mỗi line snapshot cứng `tax_rate`+`tax_amount`; thuế gom **một entry / rate group** (496 cho nhóm 10%) — không round từng dòng.

# PLAN-045 — Configurable rounding + order_conditions ledger + refund lines

## P45-1 — Rounding config (curl settings)
```
GET /api/v1/pos/settings/order:
  tax_rounding_mode        = round        (四捨五入)
  tax_rounding_decimals    = 0
  split_bill_rounding_mode = auto
  prices_include_tax       = false
  service_charge_tax_rate  = 10.00
  default_tax_type_id      = 019f69a8-…
```
**UI** — `p45-tax-rounding-tab.png`: **税額の端数処理 = 四捨五入** + ghi chú *"この設定は注文作成時にスナップショットされ、後から変更しても過去の注文は書き換わりません"* (snapshot lúc tạo đơn — đổi setting KHÔNG viết lại đơn cũ) + 端数の桁数 + 割り勘の端数処理 + デフォルト税区分 + 税込価格(内税) + サービス料税率 + 精算レポート税率内訳.
✅ Shop tự chỉnh 端数処理 + số thập phân; bất biến trên đơn cũ.

## P45-2 — 3 chế độ làm tròn (`RoundingMode` engine)
```
tax ¥183.5, step=1:
  round (四捨五入)  → 184
  ceil  (切り上げ)  → 184
  floor (切り捨て)  → 183   ← khác round/ceil
```
✅ 3 mode 切り捨て / 切り上げ / 四捨五入 cho kết quả khác nhau (floor=183 vs round=184).

## P45-3 — order_conditions ledger (audit bất biến)
```
order_conditions rows: 40   (bảng đa hình type/source/label/rate/amount/meta)
sample: type=tax  source=tax_type  rate=10%  amount=496  label="10%"
```
✅ Mọi tax/discount/refund áp dụng được ghi vào ledger lúc tạo đơn (xem P43-3).

## P45-4 — Refund = dòng âm (không sửa dòng gốc)
```
POST /pos/orders/{order}/items/{item}/refund  {quantity:1}  →  HTTP 201
items: 1 → 2
  [NEW]      qty=-1.0000  unit=1827.50  tax=-183.00   ← dòng âm được thêm
  [ORIGINAL] qty= 1.0000  unit=1827.50  tax= 183.00   ← GIỮ NGUYÊN (immutable)
```
✅ Refund **thêm dòng giá trị âm**, không bao giờ mutate dòng gốc.
