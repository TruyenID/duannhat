🚀 Quick Commands

🐳 Start Backend Stack
docker compose up -d
Backend + MySQL + Redis + MinIO + Mailpit
🌐 Start All Web Apps
pnpm dev
Admin + Customer + POS web (parallel)
🔧 Start with Tools
docker compose --profile tools up -d
+ phpMyAdmin
📱 Admin Web Only
pnpm dev:admin
http://localhost:5430
🛒 Customer Web Only
pnpm dev:customer
http://localhost:5450
💳 POS Web Only
pnpm dev:pos
http://localhost:5440
🗄️ Seed Database
docker compose exec app php artisan migrate:fresh --seed --force
Fresh DB with sample data
🧪 Run Tests
cd backend && php -d memory_limit=-1 vendor/bin/pest --compact
PHP unit/feature tests
🛑 Stop All
docker compose down
Stop all containers
📊 View Logs
docker compose logs -f app
Follow Laravel logs
🔄 Restart Backend
docker compose restart app
Restart Laravel container
📦 Composer Install
docker compose exec app composer install
Update PHP dependencies
