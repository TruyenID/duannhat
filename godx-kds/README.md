# godx-tempo-kds

Kitchen Display System for TempoFast. Vite + React 19 PWA. Plan-027.

## Development

```sh
pnpm install
pnpm dev          # http://localhost:5460
```

## Stack

- Vite 8 + React 19 + TypeScript + react-router-dom 7
- TanStack Query v5
- Tailwind CSS v4
- Laravel Echo + Pusher.js (Reverb client)
- idb (IndexedDB cache)
- vite-plugin-pwa

## Status

Initial scaffold — Phase 3 Task 3.1. See umbrella `plans/plan-027/` for full design.
